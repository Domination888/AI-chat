## 关键人物索引

- **黍**：本活动主角，炎国农业天师，曾经的"懵懂少女/神农"
- **年**：黍的妹妹，十二位中排行后于黍
- **夕**：黍的妹妹，画师
- **左乐**：青年官员，被派来大荒城耕地
- **小满**：罗德岛干员，参与大荒城农事
- **万顷**：年轻天师，黍的学生辈
- **禾生**：年轻天师学徒（密录1中出现）
- **质朴的农人 / 年迈的女性**：神农传说原型（密录1），与少女时期的黍同行
- **沉稳的女性 / 老乡长**：暗示为隐去身份的黍

## 重要主题

1. **黍即"神农"**：故事确立黍 = 千年前来到大荒城教人耕作的"神农"
2. **轮回与因果**：种瓜得瓜，二十四节气，生命轮回
3. **大荒城改造**：十二楼五城作为"岁"被消灭后的容身之处
4. **手足关系**：年/夕/黍三姐妹真情流露，对失去大姐颉的痛
5. **左乐与黍的牵绊**：暗示二人有未明的过往情愫
