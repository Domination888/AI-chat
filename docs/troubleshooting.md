# 踩坑与排障

仅记录仍有复用价值的问题机制；设备参数、运行命令和已完成状态不在这里保留。

| 症状 | 原因 | 处理与验证 |
| --- | --- | --- |
| 终端接口正常，Electron 却 Failed to fetch | Spring CORS bean 未显式交给 SecurityFilterChain，app origin 未获准 | 显式配置 CorsConfigurationSource；用 app://story 发请求验证响应头，并拒绝未授权网页 origin |
| 模型包导入成功，后续请求失败 | 重启分配了新端口，IPC bootstrap 仍返回旧基址 | 安装的 finally 同步 runner.base；验收真实导入、重连和聊天 |
| 事务服务方法正常，导出接口空指针 | 调用方直接读取 CGLIB 代理上的实例字段 | 通过服务 accessor/method 访问 JDBC/领域服务；测试实际 HTTP 导出 |
| SQLite schema 执行失败 | 用分号切 SQL，把 FTS trigger 的 BEGIN/END 拆坏 | 迁移使用明确 statement 分隔符并事务提交；保存 checksum，拒绝已执行脚本被静默更改 |
| Navicat 看不到本地测试的新消息 | 连接的是数据库副本，或表格/手动事务还停留在旧结果 | 核对 Navicat 文件路径与开发启动日志一致，刷新表格并结束旧读取事务；SQLite 不通过用户名/密码区分数据源 |
| 离线包混入运营代码 | 同一 target 目录保留上次 cloud 编译结果 | 每次切 profile 先 clean；检查 JAR、包体及导出源码的实际内容 |
| 裁剪 Java 后 Spring 启动失败 | 仅根据直接依赖选模块，遗漏框架需要的 JGSS/Instrumentation | 以 java.se 加所需 jdk 模块构建；验收打包 JRE 实际启动，不只测开发 JDK |
| llama-server 无法找到库或 Metal 后端 | Homebrew 绝对路径/@rpath 未迁移，CPU/Metal 动态后端遗漏 | 递归复制依赖与 shader，改 install_name 并重签；测试离开 Homebrew 路径的候选包 |
| 新分支回退到了错误场景 | 只复制当前状态，没有复制世界初始快照 | 同时复制初始状态；分支后回退到第一条消息验证原世界不受影响 |
| 回退后角色仍提到删除的内容 | 远程嵌入与回退并发，旧任务写回了已删除原文 | 提交和召回时核实原回合存在，清理孤儿队列/索引 |
| 历史 API 比消息表多一条 | 源数据同一消息关联多个 RP 快照，普通 LEFT JOIN 产生重复行 | 保留原快照，界面按同篇章/消息的最新快照投影，测试实际 API 消息数 |
| 合并后角色、消息或收藏错配 | 两份导出复用了自增编号或世界/篇章标识 | 按每份来源建立映射，重写全部引用，逐条核验内容与关联 |
| 早期对话不能分支/召回 | 只有 history，缺少 RP 回合 | 用原文补缺失回合并建索引；不存在的历史场景快照不能伪装为可靠记录 |
| 中文 SSE 文本破碎或 JSON 丢失 | 把网络 chunk 当成完整字符/事件，忽略 CRLF 和多行 data | 持续 UTF-8 decoder 与事件缓冲；测试半字符、半标签、取消与格式错误 |
| 停止后仍播放旧音频 | 旧异步合成请求迟到，取消只暂停现有 Audio | 请求序号作废迟到结果，回收 blob URL；切换篇章时统一停止 |
| 公网 BYOK 被拒绝 | 本机代理的 fake-IP 把公网域名映射至保留地址 | 服务部署使用真实 DNS；不要为适配 fake-IP 放开内网拦截 |
| embeddings 返回 No models loaded | 服务把 GGUF 暴露为聊天模型，未启动 embedding 模式 | 核对 /models 与 /embeddings，设置模型模式、pooling 和维度；不要用聊天模型名称猜能力 |
| 更换嵌入模型后召回为空 | 阈值沿用另一模型；向量维度或语义空间不一致 | 重建索引，按当前模型重新评测阈值；不要直接沿用小样本最佳分数 |
| RAG 半句截断/剧情节点混合 | 固定字符滑窗无视材料结构 | 兼容语料按标题、剧情节点、语音场景切分，超长材料按句子兜底 |
| 兼容 TTS 日志 Span 出现负数 | 字段时间被更新而插入顺序未重排 | 看首句到末句整体耗时与播放锚点；不能据此认定时间倒流 |
| MinIO 镜像拉取报 access denied / unauthorized | 原预构建镜像地址不再可用 | 当前 Compose 从固定官方源码构建 MinIO，并用独立 S3 初始化脚本建桶；首次构建需联网，后续复用镜像 |
| 开源源码能看但不能构建 | 依赖锁、源码入口、wrapper 的 `.mvn` 配置或模块路径没有一起导出 | 从实际导出目录执行 npm ci、Vite 构建和 Maven verify，排除对工作区依赖树的偶然依赖 |

迁移中的孤儿消息、无世界归属的 MemOS/Redis 事实应保存审阅副本。强行放入任意世界会让历史角色“记得”并未共同经历的事件。


## 真实体验审计可复用排查

| 现象 | 容易漏掉的原因 | 排查与防回归 |
| --- | --- | --- |
| 重写/重试/继续误报没有提问 | 模板emit多传字符串，父处理器收到错误索引；只测helper不会覆盖真实绑定 | 编译真实SFC模板，点击render VNode并调用实际父处理器，覆盖完成/失败/长度/手停、分页与开场安全 |
| 同一条资料只答前子问题 | 整问rank和总预算挤掉后一个子问对应细节 | 分解相关子问题，保留对应原文；按多个真实子问复验，不只比来源链接 |
| 指定旧刊却返回当前刊 | 请求期次未被解析或被current默认覆盖 | 检查明确期次与选刊参数，保留原刊期；缺资料明确失败，不借新刊凑答案 |
| 刚才两网页追问重新搜指令原句 | 网页指代未继承原主题/URL | 从保存的真实来源恢复指代，再隔离旧助手事实；原题与followup分别验 |
| 朗读时后台截图近闭嘴 | 准备/片段间隙仍显示可停止，或口型写入被motion覆盖 | 前台同次状态截图观察准备/实际播放/停止；渲染前钩子写参数，不为截图盲目放大增益 |
| 全量测试通过却XML缺失 | 后续clean覆盖target/surefire结果 | 每轮立即归档日志、exit与结果摘要；不要以随后别轮XML冒充本轮 |
| 上游401只显示通用500 | 包装异常抹掉安全分类 | 保留类型化HTTP原因并映射安全502，测试连接和实际chat均核对；勿回显凭据正文 |
| 回退地点约定正确但顶栏仍旧模式 | 同篇章回退只刷新历史/篇章，父组件会话状态缓存没有更新；面板却独立重新读取 | 检查共同 applyRewind 路径；用真实回退/编辑/重写/失败重试处理器和 Vue watcher 验状态刷新，补导航与同篇章迟到请求竞态，不靠源码字符串断言 |
| 动作入口名不同却看起来一样 | 共享列表可能多个 group/index 指向同一个素材，状态文案并不证明播放索引被吞 | 对照 model3 文件引用再判断别名；只合并重复发布入口，保留内部映射与原下标，不删除独立资源或为标签新造动画 |
| 全动作都点过却无法确认短动画 | 瞬间截图可能错过短动作，执行反馈与完整视觉过程不是同一证据 | 分列实际点击、状态、可见变化与 visual_partial；先检查前台时序，不据静态图宣称全动画成功或失效 |
| 长回复 AX 到21而继续从55开始 | 辅助功能树对长文本截断，原文实际已到55半句 | 前台定位真正尾部再判承接，保留补证撤销误判；有限次数继续后仍 length 不自动当新增故障 |
| 同日期标题 OFF 正确、ON 转泛搜索 | 讨论选刊标记已消费，后续仅有日期+期字+标题但没有日报二字，路由未必识别 | 同一完整原句在两版对照，保留显式选刊与消息文本的优先级；不能加上答案或日报二字绕过实际失败 |
| 日历时钟被说成缓存天气本地时间 | 当前环境时间与天气观测时间同时注入，标签语义不清 | 并列核当前设备时钟、观测 UTC 和同一观测当地时间；缓存题关闭搜索，不把查询时间当观测来源 |
| 普通虚构写作被未知往事限制拒绝 | 记忆防编造约束扩散到创作任务 | 区分未知共同往事与用户明确要求的虚构作品，短任务先验完整结尾；入口续写成功不证明篇幅章节完整 |

| 同一日报OFF答对ON称未提供 | 联网分支提前缩小主要资料预算，或标点先清掉导致多子问只留一个 | 保留每子问的完整相关句，核对模型实际摘录；ON/OFF统一主要预算，额外URL独立有界，不靠增加同义词掩盖缺事实 |
| 技能条数正确但固定尾句消失 | 总结布尔被误当作所有尾句权限，schema主动禁止非空closing | count/question/closing分别合并，literal用单值enum及原始/清理值双校验；默认不在尾句后追问，不渲染补造 |
| 严格格式降级后仍缺条数或尾句 | json_object只约束JSON语法，服务未收到完整schema | 最多一次兼容请求同时携带完整schema，继续本地等值与条数验证；不重放已执行工具 |
| 更正已保存、索引ready仍答旧容器 | 把ready当正确召回，或主语在前的陈述更正丢掉资格来源 | 保留原始陈述和更正provenance；分开验索引状态、同世界纠正引用和独立世界负控，不用另一版本通过冲销失败 |
| 自然第二追问丢网页 | 仅靠固定词识别指代，或把追问叠加成新主题 | 邻近可信结构化来源内做有界语义分类；保留原主题/完整URL，显式换题退出，不继承旧助手事实 |
| 管理员暂停被记成用户停止 | 所有stopped共用一个布尔原因 | 从事件源记录固定取消类别并保留第一个原因；分别验用户停止、暂停、断连、超时，旧记录不反推原因 |
| ready后本地服务死亡界面仍正常 | 只做启动检查，没有持续子进程/健康监督 | 持续监督、按服务报告与有限重试；确认死亡才重启，活着但不健康不强杀，不影响正常服务和草稿 |
| 嵌入短句正常、长句进程断言退出 | embedding完整序列超过默认physical/micro batch | 单slot并对齐ctx/batch/ubatch；边界实测请求、向量维度/有限值与进程健康，修后native通过只作aux，不算UI恢复 |
