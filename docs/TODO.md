# 待办与待审阅功能

## 发行与运行验收

- 16GB macOS、Windows 实机：安装、模型导入、30 轮、语音与内存；Windows 离线运行时需 Windows 原生构建。
- 默认离线环境断网抓包；显式公网 BYOK 的数据发送提示与服务兼容性。
- 生产 SMTP/域名/TLS、S3 备份恢复、加密/签名密钥恢复演练。
- 模型与二进制许可、对应源码义务、macOS Developer ID/公证、Windows 签名与图标。
- 新记忆方案与兼容 MemOS 使用相同固定剧本做质量、延迟、成本盲评。
- 注册与账号找回/密码重置、模型准备失败提示、首次有效对话完成率。
- 云多实例需要共享限流、队列租约和跨实例中断；当前不扩容为多实例。
- 真实麦克风回声/误触发、语音自然度和重度 RP 用户的长期体验评测。
- 正式用户条款、隐私与内容运营审核；先邀请免费测试再决定收费。
- ds完全适配 图像 关闭思维链
- 离线版的开发工具应该保留 如查看日志等功能 明确用户群体 商业版用户是毫无经验的人 离线版用户是懂一些计算机知识的人
