# AI-Chat 项目规范（Electron客户端版）

## 项目目标

将游戏剧情与角色台词搬进现实，用户可选择角色卡，通过语音或文字与AI角色进行沉浸式对话。

## 系统架构

### 整体架构
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   Electron      │    │   Spring Boot    │    │    外部服务     │
│   客户端        │◄──►│   后端服务       │◄──►│   (LM Studio)   │
└─────────────────┘    └──────────────────┘    └─────────────────┘
                              │
                    ┌─────────┼─────────┐
                    │         │         │
              ┌─────▼──┐ ┌───▼────┐ ┌───▼────┐
              │ MySQL  │ │ Redis  │ │ 服务   │
              │ 数据库 │ │ 缓存   │ │ (ASR/TTS) │
              └────────┘ └────────┘ └────────┘
```

### 目录结构
```
AI-Chat/
├── backend/                    # Spring Boot后端
│   ├── src/main/java/          # Java源代码
│   ├── src/main/resources/     # 配置文件、Mapper、Prompts
│   ├── pom.xml                 # Maven配置
│   └── init.sql                # 数据库初始化脚本
├── client/                     # Electron客户端
│   ├── electron/               # Electron主进程
│   ├── src/                    # Vue3前端代码
│   ├── package.json            # Node.js依赖
│   └── vite.config.js          # Vite配置
├── services/                   # 独立服务
│   ├── gpt-sovits/             # GPT-SoVITS TTS服务
│   ├── sense-voice/            # SenseVoice ASR服务
│   └── prime-mcp-server/       # MCP工具服务
├── docs/                       # 项目文档
└── scripts/                    # 构建和部署脚本
```

## 技术规范

### 前端（Electron + Vue3）
- **框架**: Vue3 + Vite + Element Plus
- **状态管理**: Vue Composition API
- **样式**: Element Plus组件库
- **构建**: Vite + Electron Builder
- **通信**: IPC（主进程与渲染进程）

### 后端（Spring Boot）
- **框架**: Spring Boot 3.x
- **ORM**: MyBatis
- **AI集成**: LangChain4j
- **数据库**: MySQL 8.x
- **缓存**: Redis
- **API**: RESTful

### 外部服务
- **LLM**: LM Studio（OpenAI兼容）
- **ASR**: SenseVoice（本地）
- **TTS**: GPT-SoVITS（本地）

## 开发规范

### 代码组织
1. **模块化**: 按功能模块组织代码
2. **命名规范**: 使用有意义的英文命名
3. **注释**: 关键逻辑必须添加注释
4. **错误处理**: 必须有完善的错误处理机制

### API设计
1. **RESTful风格**: 使用标准HTTP方法
2. **统一响应格式**:
   ```json
   {
     "code": 200,
     "message": "success",
     "data": {}
   }
   ```
3. **错误码规范**: 统一定义错误码
4. **版本控制**: API路径包含版本号

### 数据库设计
1. **表命名**: 使用下划线命名法
2. **字段命名**: 使用下划线命名法
3. **索引**: 关键查询字段建立索引
4. **外键**: 合理使用外键约束
