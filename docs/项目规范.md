# AI-Chat 项目规范（Electron客户端版）

## 项目目标

将游戏剧情与角色台词搬进现实，用户可选择角色卡，通过语音或文字与AI角色进行沉浸式对话。

## 技术规范

### 前端（Electron + Vue3）
- **框架**: Vue3 + Vite + Element Plus
- **状态管理**: Vue Composition API
- **样式**: Element Plus组件库
- **构建**: Vite + Electron Builder
- **通信**: IPC（主进程与渲染进程）

### 后端（Spring Boot）
- **框架**: Spring Boot 3.x
- **ORM**: MyBatis
- **AI集成**: LangChain4j
- **数据库**: MySQL 8.x
- **缓存**: Redis
- **API**: RESTful

### 外部服务
- **LLM**: LM Studio（OpenAI兼容）
- **ASR**: SenseVoice（本地）
- **TTS**: GPT-SoVITS（本地）

### API 架构

**统一聊天入口**：语音输入和文本输入只是输入方式的选择，功能完全一致。

```
POST /api/chat          → 统一流式聊天入口（SSE）
  inputMode=text        → 文本输入：直接走 LLM
  inputMode=audio       → 语音输入：先 ASR → 再走 LLM
  两者都支持：联网搜索、RAG、MCP 工具、多模态（图片）、TTS 回播

POST /api/audio/asr     → 独立 ASR 工具接口
GET  /api/audio/tts     → 独立 TTS 工具接口
```

SSE 事件协议（语音/文本统一）：
- `event: asr`   — 仅语音输入时，ASR 识别结果
- `event: text`  — LLM 流式文本 delta
- `event: tts`   — 句子级 TTS 音频 chunk（需 ttsVoiceId 时才有）
- `event: done`  — 流结束
- `event: error` — 错误
