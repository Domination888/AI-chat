# 项目目录重构规划

## 当前问题
- 前端代码放在后端项目根目录的frontend/中
- 非后端模块（如GPT-SoVITS、SenseVoice）都在后端根目录
- 缺乏清晰的客户端应用结构

## 新的目录结构

```
AI-Chat/
├── backend/                    # Spring Boot后端（原项目根目录）
│   ├── src/
│   ├── pom.xml
│   └── ...
├── client/                     # Electron客户端应用（新）
│   ├── electron/               # Electron主进程代码
│   ├── src/                    # Vue3前端代码（来自frontend/）
│   ├── package.json            # Electron应用配置
│   └── ...
├── services/                   # 独立服务（非后端模块）
│   ├── gpt-sovits/             # GPT-SoVITS服务
│   ├── sense-voice/            # SenseVoice ASR服务
│   └── prime-mcp-server/       # MCP工具服务
├── docs/                       # 项目文档
└── scripts/                    # 部署和构建脚本
```

## 迁移计划

### Phase 1: 创建新目录结构
1. 创建backend/目录，将当前项目根目录内容迁移进去
2. 创建client/目录，准备Electron应用
3. 创建services/目录，重新组织独立服务

### Phase 2: 迁移前端到Electron
1. 将frontend/内容迁移到client/src/
2. 设置Electron主进程
3. 配置Electron与后端的通信

### Phase 3: 重构服务
1. 将GPT-SoVITS迁移到services/gpt-sovits/
2. 组织其他独立服务

### Phase 4: 更新配置和文档
1. 更新构建脚本
2. 更新README和文档
3. 测试完整流程
