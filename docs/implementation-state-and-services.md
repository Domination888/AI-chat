## 3. 场景、分支与上下文预算

`RpState` 保存故事模式、表达风格、地点、时间、人物身份、关系、事件、约定和场外指导。完整状态入库；Prompt 中的状态按字段预算压缩，保留最近事件与有限约定。近期历史最多读取 16 条，再由 `PromptBudget` 按保守字符估算约束总预算，并保留当前输入。该估算不是模型 tokenizer 的精确计数。

`RpSessionService` 管理篇章到世界的关系，历史回合快照是回退依据。分支复制消息并重建编号、创建独立世界；初始快照也被复制，避免在新分支回退到错误起点。收藏保存在回合，图片通过附件引用进入相册。

新分支以源篇章的当前标题命名为“源标题 · 分支 N”。事务内锁定该用户的篇章并避让已用标题，其他用户的同名篇章不占序号；原篇章和已建分支不被重命名。分支复制原回合的记录时间，不把复制时刻当成事件发生时刻。

对话顶部区分“独立新故事”和“延续新章”；后者读取当前篇章的世界并延续，切换篇章后不应用过期响应。场景面板中的“延续世界线，开启新章”会先完整保存当前表单（含约定与重要经历）；保存失败保留输入，成功后才创建续章。操作期间锁定按钮，面板关闭或切换篇章后忽略旧请求响应。

现实陪伴模式使用账号保存的时区、城市、设备位置、查询时天气、农历、节气和节日；初始时区为系统时区或 Asia/Shanghai。通用搜索和后台兴趣研究分别显式开启，Skill 与 MCP 按账号管理。主动回复使用同一角色生成与提交路径，不伪造用户消息。

V5 additive迁移添加`rp_turn.before_state_json`，新回合保存执行前场景，回退优先目标之前状态，导出导入保留字段。旧历史没有before只能fallback，不能补造当时未保存的手动场景快照。

## 4. 记忆索引

`StoryStore.finish` 在提交回合时插入 `index_queue`，消费者跳过状态不为 complete 的回合。`MemoryIndex` 每 3 秒处理最多 4 条，取已完成回合的原文，最多 2400 字符，生成 1024 维嵌入。成功写 memory_entry；失败指数退避，最多 8 次后标 failed。设置面板可以查看状态并重试失败任务。

- 云端：pgvector 余弦距离排序，限定世界和嵌入模型，取前三条。
- 本地：扫描当前世界最新 1000 条同模型向量，余弦分数大于 0.45 后取前三条；另用 FTS5 trigram 查短语，合并去重后最多注入四条。
- 远程嵌入完成后和召回时均检查原回合仍存在，避免回退期间的旧事实重新进入 Prompt。
- 原文和世界快照为权威数据，向量是派生索引。归属不明的外部记忆不自动分配给角色或世界。
- 记忆面板从已完成回合逐条展示来源，即使嵌入索引尚未完成或失败，也可立即纠正与停用，并标示索引状态。纠正不修改历史原文，立即进入权威纠正上下文并触发重建；停用项不参与召回，也排除在自动拼接的跨章最近经历之外。原聊天记录与用户手动填写的场景仍保留。

原生回合写入 TEXT 时间字段时显式保存带 UTC 标记的 `Instant`；兼容 MySQL 的 TIMESTAMP 写入仍使用时间戳类型。界面把已注明偏移的时间转换为本机时区，兼容 PostgreSQL 的短偏移与微秒格式，并显示实际时区。旧导入值未注明时区时保留不确定性，不擅自按 UTC 或当前时区换算。

过去问题使用有界最多16条、2400token的可靠原文清单，合并当前用户原话和有效更正；模型只返回kind/evidence编号，`PastFactAnswer`只引用合法原文并关联historyIds。role/action过滤个人偏好或单人行为，不能以此证明共同交换。无材料返回NOTICE；有材料但无对应或不确定返回UNMATCHED，不宣称整个世界无数据；未找到标记memoryUnavailable避免反复索引。`sourceTypes`区分当前commitments/events与用户原话，提议标计划而非已发生。别名、泛指、手动约定和具体计划可走正常路径，但同主体同动作的不同事件、超出清单的别名仍不保证选择完全准确。本轮背景、创作和旧诗内容不强制套共同过去未知答复。

## 5. 认证、BYOK 与运营

商业 `CloudIdentity` 使用 BCrypt cost 12；邀请码和验证码只保存哈希，验证码有效期 10 分钟并限制尝试次数。邀请码单次使用，注册在事务与锁内消费。access token 为随机不透明字符串，15 分钟有效；refresh token 30 天有效，刷新时旋转并使旧令牌失效。数据库只保存 token 哈希。

管理员使用单独登录入口和 TOTP。后台 API 只提供账号信息、账号状态、用量、故障类别和操作审计，没有私人对话正文入口。暂停账号会停止其活动流并使后续认证失败。

桌面 refresh token 通过 Electron safeStorage 保存；access token 只在页面内存。浏览器后台会话保存在内存，刷新页面后重新登录。CORS 明确配置 app origin 与授权开发 origin。

浏览器只保存非敏感服务地址。会话刷新失败后进入登录页，未发送的文字和照片暂存在当前页面内存；同服务、同账号重新登录后恢复原篇章草稿，不自动发送，刷新页面会丢失该临时草稿。

主动退出登录会清除当前篇章、角色、历史与面板状态；普通重新登录回到故事库，从“继续故事”加载真实历史。此路径与过期重登的同账号草稿恢复分开处理。

模型密钥 AES-GCM 加密，AAD 绑定账号。保存后 API 只返回 hasKey 等元数据。云 BYOK 限公开 HTTPS/443、禁止重定向，DNS/IP 校验与出站 CONNECT 代理共同阻止内网访问。BYOK 当前只替换聊天模型，嵌入和语音仍用平台配置。

本地自定义密钥用数据目录 `.credentials-key` 加密。默认只接受回环地址；配置公网 API 需要前端明确开启 allowNetwork。该开关仅授权用户填写的聊天服务，不是账号同步。

云端日请求额度默认平台 100、自带模型 1000，可通过环境变量调整；失败请求也已占用预留额度。响应无实际 usage 时标 estimated。已认证账号另受每分钟 200 请求限制；超出后返回中文原因、剩余等待秒数和 Retry-After，未通过预占的请求不调用模型或增加对话历史。普通 JSON 请求体上限 25MiB，本地导入上限 128MiB。并发/限流和消费者当前属于单实例范围。

`OpenAiTransport.visibleAnswerOptions`用于complete和stream，仅`api.deepseek.com`官方host且deepseek-*模型显式关闭thinking，避免可见答复预算被推理消耗；stream预算仍为1200，tools规划不受此修改。[官方thinking说明](https://api-docs.deepseek.com/guides/thinking_mode/)解释默认模式。其它服务商不套该专有参数，也不能据此断言所有历史空答同因。模型连接测试将上游认证等错误安全分类为502响应，避免原始密钥或服务正文回显，不混淆本应用会话失效。云端删号清本人fault关联，保留他人故障。

## 6. 附件、语音与数据导出

附件支持 PNG/JPEG/WebP，单张最多 5MiB、一次最多 5 张；服务端检查格式、所有者和引用。读取链接含一小时有效的签名，不把 API bearer 放入图片 URL。删除篇章时只清理无引用对象，分支保持附件链接。

离线恢复按备份中的附件标识复用新本地文件；用户消息、回合与独立分支引用同一张照片时只导入一次，并为每个篇章保留引用关系，避免重复恢复导致文件数增长。

两版均由 Java VoiceGateway 调用 ASR/TTS。ASR 使用配置的 OpenAI 兼容 transcription 端点；本地签名模型包提供 SenseVoiceSmall。完整离线包由 OfflineRunner 默认选择包内 Kokoro，显式 STORY_TTS_ENGINE 或 STORY_ASTRA_URL 优先；独立后端的默认引擎仍为 Astra。Astra 按角色 voice_id 解析 avatars 中的黍（Shu_2），将 32kHz float32 流转为 PCM16 WAV；极短句走 WAV 批量端点，流式失败也回到相同音色的批量端点。未指定音色的角色使用配置的默认或可用音色，明确指定但不存在的音色报错。两种引擎均跳过括号动作旁白并校验有效音频。关闭自动朗读后仍可手动朗读；取消会覆盖等待、合成和播放阶段。商业部署由服务端配置平台地址/密钥，客户端只访问商业 API。

签名包中的 ONNX 服务保留受限 ffmpeg 解码：限制格式、协议、时长，最长两分钟，不允许录音引用网络资源，绑定回环并验证 token。现有 Astra 程序与音色通过显式地址复用，当前不自动打进通用离线模型包。

Astra 朗读包含 AI 等英文字母的句子时，同时允许中文和英文识别，流式与批量降级使用一致语言列表；纯中文仍使用中文。避免把混合语言被拒绝误报为整个语音服务不可用。

等待合成与播放时均提供“停止朗读”。单段语音请求和音频正文读取共用六十秒截止时间；超时后说明原因，后续同回合语句不反复报错，重新朗读或下一轮可恢复。停止会解除旧请求对队列的占用，即使旧服务未及时响应取消也不会阻塞下一次朗读。麦克风支持“取消录音”，离开篇章页面或切换故事时释放设备且不发送旧录音；正常结束录音仍经 ASR 后发送。

故事导出包含角色、完整角色卡与背景资料、篇章、历史、世界、回合、收藏、语音记录、原始附件、消息来源、记忆反馈、技能和候选话题；不包含账号密码、模型密钥或 MCP 凭据。本地导入仅接受没有故事的目录，允许已有预置角色。编号由合并工具重映射，内容原样核验；相同只读示例角色复用，同一用户下全部角色字段及完整角色资料相同的私人角色也复用，其他角色私有化。不同所有者或内容不同的角色不会误合并。没有 RP 回合的旧历史建立原文回合以重建索引；不存在的历史状态不应被解释成已验证的过去事实。

朗读分别暴露准备和播放阶段，准备时可取消；“停止”控件不单独证明WAV正在播放。WebAudio analyser的口型参数在Cubism `beforeModelUpdate`阶段写入，避免被motion/physics随后覆盖；stop解绑钩子。保留原增益，自动朗读、停止恢复和切章取消使用同一队列代次控制。清空/导入同时清两类缓冲草稿、旧播放/消息状态，并重置bundled角色导入标记再载入资料，恢复黍入口。现场音质及音画时序需单独验收，不由状态按钮推断。
