# HS-1 赴大荒 · 行动后 · 场景06「嗯_禾生」

> 同场人物：禾生、黍

禾生：乙号区域，活性率百分之二十三，产量一百五十斤；丙号区域，百分之二十五，存活率，几乎为零......
禾生：各项数据和上一季几乎没有变化，比再上一季的进展，也几乎可以忽略不计。其他几种作物试验区，情况也差不多。
黍：嗯，我知道了。
禾生：......您好像一点都不失望。
黍：很多事情急是没有用的，必须一步一步来。
禾生：百分之二十五，始终是个跨不过的坎，土地中源石活性率一旦超过了这个值，不管是庄稼还是修复土地的植物，存活率都会断崖式下跌。
禾生：可是这个数字，比起绝大部分自然土地中的源石活性率，简直不值一提......
黍：想放弃了？
禾生：不——
禾生：我只是不确定......如果最终只能得到这个结果，“万顷”这项研究，根本没有推广应用的可能。
禾生：......这么多年了，别说成果，一点希望的苗头都看不到。
